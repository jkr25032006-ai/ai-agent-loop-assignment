# AI Agent Loop Demo

## Project Overview
This project demonstrates a ReAct (Reasoning and Acting) AI Agent using Python and Google's Gemini API.

The agent follows a continuous loop in which it:
- Receives a user question.
- Reasons about the question.
- Calls a search tool when required.
- Retrieves relevant information from documents.
- Generates a final response based on the retrieved information.

## Technologies Used
- Python
- Google Gemini API
- Google Colab
- Google Generative AI
- Jupyter Notebook

## Features
- Document-based information retrieval.
- Tool calling using Gemini.
- ReAct agent loop implementation.
- Follow-up question handling.
- API key management using Google Colab Secrets.

## How to Run
1. Open the notebook in Google Colab.
2. Configure your Gemini API key in Colab Secrets using `GOOGLE_API_KEY`.
3. Enable notebook access for the secret.
4. Run all notebook cells.
5. Ask questions and observe the agent's responses.
